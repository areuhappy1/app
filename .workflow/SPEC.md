# 꽃 주문함 개선

## 사용자 요청
- 주문자 이름과 지역을 목록에서 쉽게 구분하고 검색한다.
- 등록된 주문 카드를 누르면 읽기 전용 상세보기에서 전체 정보와 원본 대화를 확인한다.
- 처리할 주문의 존재를 알려준다: 새 주문, 수령 임박, 시간이 지난 미완료 주문.
- 기획 → 구현 → 검수 순서로 진행한다.

## 수용 기준
- 지역은 별도 수정 가능한 값이며 기존 주문은 주소에서 보수적으로 추출한다. 주문자와 수령인을 구분한다.
- 카드 클릭 및 키보드로 상세보기를 열고 닫으며 수정/상태 버튼과 전화 링크가 충돌하지 않는다.
- 상세보기에서 수정, 확인 문구 복사, 캘린더 저장을 지원한다.
- 화면 상단 알림함은 검색/날짜 필터와 무관하게 미완료 주문을 보여준다. 확인과 10분 미루기는 완료와 구분한다.
- 브라우저 알림 권한은 사용자 버튼으로 요청한다. 거부/미지원이어도 앱 내 알림은 작동한다.
- 수령 60분 전 기본 알림, 지연 알림, 미정 날짜/시간을 구분하고 완료/삭제한 주문은 알림에서 제거한다.
- 앱을 닫은 상태의 서버 푸시는 이번 프런트엔드 수정만으로 제공하지 않는다. 화면에 제약을 명시하고 일정 파일의 캘린더 알림을 제공한다.
- 기존 서버 JSON 주문 저장, 백업, 가져오기와 호환된다. 운영 데이터는 검증에 사용하지 않는다.

## 검증
기존 파서 회귀 테스트 + 지역/알림 시각/미루기/완료 제외 테스트 + 브라우저에서 등록→검색→상세→수정→알림 확인.
