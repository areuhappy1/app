pH Color Analyzer V6

파일 구성
- ph_color_analyzer_v6.py : 프로그램 (화면)
- ph_core.py              : 색 계산 / 예측 / 정확도 검사 (반드시 같은 폴더에)
- test_ph_core.py         : 자체 검사 (빌드할 때 자동 실행)
- BUILD_EXE_V6.bat        : EXE 만들기

V6 변경점 (V5 대비)

1. 한글 경로 사진 읽기 문제 수정
   사용자 이름이나 폴더 이름에 한글이 있어도 사진이 열립니다.
   (V5의 cv2.imread는 Windows 한글 경로를 못 읽음)

2. 흰색/회색 기준 카드로 색 보정 (선택, 권장)
   [흰색/회색 기준 카드로 색 보정] 체크 시:
   - 사진마다 시험지 영역을 고른 뒤, 기준 카드 영역을 한 번 더 고릅니다.
   - 조명 색(형광등/햇빛)과 밝기 차이를 기준 카드로 자동 보정합니다.
   - 매번 같은 카드(흰 종이 또는 회색 카드)를 시험지 옆에 두고 찍으세요.
   - 보정 사용/미사용 기준색은 따로 저장됩니다. 체크 후 기준색을 새로 등록하세요.
   - 자동 폴더 측정도 [자동 측정영역 설정]에서 기준 카드 위치를 함께 지정합니다.

3. 정확한 색 계산
   - 실제 CIE Lab 값과 CIEDE2000 색차(ΔE) 사용
   - 반사광(하얗게 날아간 부분), 너무 어두운 부분, 튀는 픽셀 자동 제외
   - 결과 아래에 반사광 비율, 색 불균일, 기준 범위 밖 경고 표시

4. 새 예측 방식: pH 곡선 투영 (기본값)
   기준색을 pH 순서로 이은 선 위에서 위치를 찾아 pH를 계산합니다.
   색이 비슷하지만 pH가 먼 기준이 섞이지 않고,
   기준 범위 밖의 색이면 "기준색 범위 밖"이라고 알려줍니다.
   V5 방식(가까운 기준 3개 평균)도 [예측 방식]에서 선택할 수 있습니다.

5. 정확도 검사 (교차검증)
   [정확도 검사] 버튼 → 두 예측 방식의 평균/최대 오차를 숫자로 보여주고
   더 정확한 방식을 권장합니다.
   - 보간 검사: pH 기준 하나를 통째로 빼고 예측 (실제 사용에 가까운 값)
   - 사진 검사: 기준 사진을 한 장씩 빼고 예측
   상세 결과: pH_Analyzer_Data\accuracy_report_v6.csv

6. 자동 폴더 측정 개선
   - 프로그램을 다시 켜도 이미 측정한 사진은 다시 측정하지 않습니다.
   - 감시 시작 시 폴더에 있던 기존 사진을 측정할지 물어봅니다.
   - 분석에 실패한 사진은 같은 오류를 10초마다 반복하지 않습니다.
   - 일부 사진이 실패해도 나머지 사진은 계속 측정합니다.

7. 색표 모드 (기준색 등록 없이 상자 색표로 측정)
   시험지 상자의 색표를 시험지 옆에 두고 한 사진에 같이 찍으면,
   같은 사진 속 색표 칸들과 시험지를 직접 비교해 pH를 계산합니다.
   색표와 시험지가 같은 조명을 받으므로 조명이 바뀌어도 비교 결과가 유지됩니다.

   처음 한 번: [색표 설정]
   1) 색표와 시험지가 함께 찍힌 사진 선택
   2) 색표 칸을 낮은 pH부터 순서대로 하나씩 드래그 → Space (다 고르면 Esc)
   3) 칸별 pH 입력 (예: 4, 5, 6, 7, 8, 9, 10)
   4) 시험지 색 부분 드래그 → Enter
   5) 위치 확인 그림이 뜨면 아무 키나 눌러 닫기 → 색표 자체 검사 결과 표시

   그 다음부터: "비교 기준: 사진 속 상자 색표" 선택 후
   [사진 선택하고 바로 측정] → 영역 선택 없이 바로 결과.
   자동 폴더 측정도 같은 위치로 동작합니다 (자동 측정영역 설정 불필요).

   색표 기억 방식:
   - chart_profile_v6.json 에 "칸 위치(사진 크기 대비 비율)"와 "칸별 pH"만 저장.
   - 색 자체는 저장하지 않고, 측정할 때마다 그 사진의 색표에서 새로 읽습니다.
   - 프로그램을 꺼도 유지되며, 다시 [색표 설정]을 하면 이전 설정은 백업 후 교체됩니다.
   - 그래서 색표와 시험지를 매번 같은 자리에 두고 찍어야 합니다 (바닥에 테이프 표시).

   주의: 정확도는 색표 간격(보통 1 pH)의 한계가 있어 대략 ±0.3~0.5 pH 정도로 보세요.
   인쇄 색과 실제 시험지 색이 다를 수 있으니 pH를 아는 시료로 한 번 확인하고
   차이가 일정하면 현장 보정값으로 맞추세요.

데이터 (C:\Users\사용자이름\pH_Analyzer_Data)
- ph_training_v6.csv : V6 기준색. 처음 실행할 때 V5 기준색(ph_training.csv)을
                       자동으로 변환해 만듭니다. V5 원본 파일은 그대로 남습니다.
- ph_results_v6.csv  : V6 측정 결과
- site_profiles.json : 현장 보정값 (V5와 공유)
- config_v6.json     : V6 설정 (처음에는 V5 설정을 이어받음)
- chart_profile_v6.json : 색표 칸 위치와 pH
- [학습 데이터 전체 초기화]는 파일을 지우지 않고 백업 파일로 이름을 바꿉니다.

권장 사용 순서
1. 촬영 조건 고정 (조명 상자, 거치대, 카메라 화이트밸런스/노출 고정)
2. [흰색/회색 기준 카드로 색 보정] 체크
3. pH를 아는 표준 완충액으로 pH마다 3~5장씩 기준색 등록
   (최소 3개 pH 이상, 측정할 범위의 양 끝보다 넓게)
4. [정확도 검사]로 오차 확인 → 권장 예측 방식 선택
5. 현장 보정값/직접 입력은 정확도 검사 후에도 일정한 차이가 있을 때만 사용

IMPORTANT
- 프로그램이 예측한 값으로 학습시키지 마세요. 실제 pH를 아는 시료만 사용하세요.
- V5에서 저장한 현장 보정값은 V6에서도 그대로 적용됩니다.
  색 보정 모드로 바꿨다면 [현장 보정값 0으로 초기화] 후 다시 확인하세요.

BUILD EXE
1. 압축을 풀고 BUILD_EXE_V6.bat 더블클릭
2. 자체 검사 통과 후 SUCCESS가 나올 때까지 대기
3. dist\pH_Analyzer_v6.exe 실행
