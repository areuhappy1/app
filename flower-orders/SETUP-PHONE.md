# 휴대폰 설정: 카톡·문자 주문 자동 수집 (MacroDroid)

주문 받는 **안드로이드 폰**에 무료 앱 **MacroDroid**를 깔고, 카톡·문자가 오면 서버로 보내도록 두 가지 규칙(매크로)을 만듭니다. 한 번만 하면 됩니다.

> 필요한 것: **수집 키** (Claude가 채팅으로 알려드린 32자리 키). 이 키는 저장소에 올리지 마세요.

서버 주소 (두 매크로 공통)
```
https://aqknqsweeasqlqreqvxk.supabase.co/functions/v1/flower/ingest
```

## 0. 먼저 확인할 것
1. **카카오톡 → 설정 → 알림 → 메시지 미리보기 켜기** (꺼져 있으면 "새로운 메시지"라고만 와서 내용을 못 읽어요)
2. Play 스토어에서 **MacroDroid** 설치 → 처음 실행 때 나오는 권한 요청은 모두 허용
3. **설정 → 애플리케이션 → MacroDroid → 배터리 → 제한 없음** (삼성은 "사용하지 않는 앱 절전"에서도 빼 주세요)

## 1. 카톡 매크로
1. MacroDroid → **매크로 추가**
2. **트리거 +** → 기기 이벤트/알림 → **알림 수신(Notification Received)**
   → 앱 선택: **카카오톡** → 내용: **모든 내용(Any content)**
   → "알림 접근 권한"을 물으면 허용
3. **액션 +** → 웹 → **HTTP 요청(HTTP Request)**
   - 방식(Method): **POST**
   - URL: 위 서버 주소
   - **쿼리 매개변수(Query parameters)** 에 아래 4개 추가
     | 이름 | 값 |
     |---|---|
     | `key` | 수집 키 |
     | `source` | `kakao` |
     | `sender` | `...` 버튼 → **알림 제목 (Notification title)** |
     | `text` | `...` 버튼 → **알림 텍스트 (Notification text)** |
4. 이름을 `꽃 주문 - 카톡`으로 저장

## 2. 문자 매크로
1. **매크로 추가**
2. **트리거 +** → 전화/SMS → **SMS 수신(SMS Received)** → 모든 번호, 모든 내용
3. **액션 +** → **HTTP 요청**, POST, 같은 서버 주소, 쿼리 매개변수:
   | 이름 | 값 |
   |---|---|
   | `key` | 수집 키 |
   | `source` | `sms` |
   | `sender` | `...` → **SMS 보낸 사람 이름 (Contact name)** |
   | `phone` | `...` → **SMS 번호 (SMS number)** |
   | `text` | `...` → **SMS 메시지 (SMS message)** |
4. 이름을 `꽃 주문 - 문자`로 저장

> 삼성 메시지의 **채팅+(RCS)** 로 온 문자는 "SMS 수신"에 잡히지 않을 수 있어요. 그럴 땐 1번 카톡 매크로를 복사해서 앱을 **메시지**로 바꾸고 `source` 값을 `sms`로 바꾼 매크로를 하나 더 만드세요.

## 3. 확인
1. 다른 폰으로 이 폰에 "내일 3시 꽃다발 픽업 가능할까요?"라고 카톡이나 문자를 보냅니다.
2. 주문 목록 페이지를 열고 ⚙︎ 설정에 **매장 비밀번호**를 넣으면, 20초 안에 **새로 들어온 주문**에 나타납니다.

## 잘 안 될 때
- 아무것도 안 들어옴 → MacroDroid 앱의 **로그(시스템 로그/매크로 로그)** 에서 매크로가 실행됐는지 확인. 실행 안 됐으면 알림 접근 권한·배터리 설정 확인
- 내용이 "새로운 메시지"로만 옴 → 카톡 메시지 미리보기 켜기
- 같은 메시지가 두 번 → 3분 안의 같은 내용은 서버가 자동으로 걸러요
