# 휴대폰 설정: 카톡·문자 주문 자동 수집 (MacroDroid)

주문 받는 **안드로이드 폰**에 무료 앱 **MacroDroid**를 깔고,
"카톡(또는 문자) 알림이 뜨면 → 그 내용을 서버로 보내기" 규칙(매크로)을 2개 만듭니다. 한 번만 하면 됩니다.

> 필요한 것: **수집 키** (Claude가 채팅으로 알려드린 32자리 키). 이 키는 저장소에 올리거나 남에게 보내지 마세요.

아래에서 `수집키` 부분을 실제 키로 바꿔 쓰세요.

| 매크로 | 보낼 주소 |
|---|---|
| 카톡 | `https://aqknqsweeasqlqreqvxk.supabase.co/functions/v1/flower/ingest?key=수집키&source=kakao` |
| 문자 | `https://aqknqsweeasqlqreqvxk.supabase.co/functions/v1/flower/ingest?key=수집키&source=sms` |

## 0. 준비 (5분)
1. **카카오톡 알림 내용 보이게 하기**
   카카오톡 → 오른쪽 아래 **더보기(…)** → 오른쪽 위 **⚙ 설정** → **알림** →
   **메시지 알림 켜기**, **메시지 미리보기(내용 표시) 켜기**.
   꺼져 있으면 알림에 "새로운 메시지"라고만 와서 주문 내용을 못 읽어요.
2. Play 스토어에서 **MacroDroid** 설치 (무료판으로 충분해요. 매크로 5개까지 무료)
3. MacroDroid를 처음 열면 나오는 안내는 **건너뛰기/다음**으로 넘기세요.
4. **배터리 제한 풀기** (안 하면 폰이 잠든 사이 멈춰요)
   휴대폰 **설정 → 애플리케이션 → MacroDroid → 배터리 → 제한 없음**
   (삼성) **설정 → 배터리 → 백그라운드 사용 제한 → 절전 예외 앱 → MacroDroid 추가**

## 1. 카톡 매크로 만들기
1. MacroDroid 첫 화면 → **매크로 추가(Add Macro)**
2. **트리거(빨간 칸)의 +** → 위쪽 **🔍 검색**에 `알림` (영어면 `Notification`) 입력 → **알림(Notification)** 선택
   - **알림 수신(Notification Received)** 선택 → 확인
   - 앱 고르기 화면: **앱 선택(Select Application)** → 목록에서 **카카오톡** 체크 → 확인
   - 내용 조건: **모든 내용(Any Content)** → 확인
   - **알림 접근 권한**을 켜라는 창이 뜨면: 이동 → **MacroDroid 켜기** → 뒤로가기
3. **액션(파란 칸)의 +** → 🔍 검색에 `HTTP` → **HTTP 요청(HTTP Request)** 선택
   - **요청 방식(Request method)**: `POST`
   - **URL**: 위 표의 **카톡 주소** 붙여넣기
   - **쿼리 매개변수(Query Parameters)** 탭 → **+** 로 2개 추가
     | 이름(Name) | 값(Value) |
     |---|---|
     | `sender` | 값 칸 옆 **…(점 세 개)** → **알림(Notification)** → **알림 제목(Notification title)** |
     | `text` | **…** → **알림(Notification)** → **알림 텍스트(Notification text)** |

     고르면 값 칸에 `[not_title]`, `[notification]` 같은 대괄호 글자가 들어가요. 정상입니다.
   - 오른쪽 위 **✓(확인)**
4. 제약조건(초록 칸)은 비워 둡니다.
5. 맨 위 매크로 이름을 `꽃 주문 - 카톡`으로 바꾸고 **💾 저장(오른쪽 아래)**

## 2. 문자 매크로 만들기 (카톡 매크로 복사)
1. 첫 화면 → **매크로** 목록 → `꽃 주문 - 카톡` 길게 누르기 → **복제(Clone)**
2. 복제된 매크로를 열고:
   - 트리거를 눌러 앱을 **카카오톡 → 메시지**(삼성 기본 문자앱. 구글 메시지를 쓰면 **Messages**)로 바꾸기
   - HTTP 요청을 눌러 URL 끝의 `source=kakao`를 **`source=sms`** 로 바꾸기
3. 이름을 `꽃 주문 - 문자`로 바꾸고 저장

## 3. 켜져 있는지 확인
- MacroDroid **매크로** 목록에서 두 매크로 오른쪽 스위치가 **켜짐**인지 확인하세요.

## 4. 테스트
1. 가족·직원 폰에서 이 폰으로 **카톡**을 보냅니다: `내일 3시 꽃다발 픽업 가능할까요?`
   (나와의 채팅은 알림이 안 떠서 테스트가 안 돼요)
2. **문자**도 하나 보냅니다.
3. 주문 목록 페이지(⚙︎ 설정에 매장 비밀번호를 넣은 상태)에서 20초 안에 **새로 들어온 주문**에 나타나면 성공!

## 안 될 때
| 증상 | 확인할 것 |
|---|---|
| 아무것도 안 들어옴 | MacroDroid → 왼쪽 위 메뉴(≡) → **시스템 로그**에 매크로 실행 기록이 있는지. 없으면 알림 접근 권한·배터리 설정·매크로 스위치 확인 |
| 로그엔 실행됐는데 안 들어옴 | URL에 수집 키가 정확한지(앞뒤 공백 없이), 인터넷 연결 확인 |
| 내용이 "새로운 메시지"로만 옴 | 카톡 **메시지 미리보기** 켜기 |
| 이름 대신 "카카오톡"이 옴 | 여러 메시지가 한 알림으로 묶인 경우예요. 대부분은 메시지마다 따로 들어와요 |
| 같은 메시지가 두 번 | 3분 안의 같은 내용은 서버가 자동으로 걸러요 |
