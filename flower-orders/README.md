# 꽃 주문함

카톡·문자로 받은 꽃 주문을 **붙여넣기만 하면** 주문 목록으로 정리해 주는 웹앱입니다. 서버 없이 브라우저에서만 동작합니다.

## 쓰는 법
1. **＋ 주문 넣기**를 누르고 대화를 넣습니다. 방법은 셋 중 하나입니다.
   - 카톡 대화방 → 메뉴 → **대화 내보내기** 파일 열기
   - 카톡 메시지를 길게 눌러 **복사**한 뒤 붙여넣기
   - 문자 내용 붙여넣기 (여러 건이면 빈 줄 두 줄로 구분)
   - **🖼️ 사진·캡처 읽기**: 카톡·문자 캡처나 주문서 사진에서 글자를 읽어 채웁니다 (PC에서는 이미지를 입력칸에 붙여넣거나 끌어다 놓아도 됨).
     브라우저 안에서 Tesseract.js로 읽고 사진은 서버로 보내지 않습니다. 처음 한 번은 한국어 인식 파일(약 10MB)을 받습니다.
2. **주문 찾기**를 누르면 고객, 연락처, 상품, 금액, 날짜·시간, 픽업/배송, 배송지, 받는 분, 리본·카드 문구, 입금 여부가 자동으로 채워집니다.
3. 내용을 확인·수정하고 **등록**합니다.
4. **주문 목록**에서 날짜별로 보고, 상태 버튼(접수 → 제작중 → 준비완료 → 완료)을 눌러 진행 상황을 바꿉니다. **확인 메시지 복사**로 손님에게 보낼 확인 문구도 만들 수 있습니다.

### 가장 빠른 방법: 공유하기
휴대폰(안드로이드 크롬)에서 사이트를 열고 **메뉴(⋮) → 앱 설치(홈 화면에 추가)** 를 한 번 해 두면,
- 카톡·문자 메시지를 길게 눌러 **공유 → 꽃 주문함**
- 갤러리의 캡처 사진에서 **공유 → 꽃 주문함** (여러 장 가능)

으로 보내는 즉시 글자를 읽고 주문서가 채워집니다. (아이폰은 공유 대상 등록을 지원하지 않아 앱 안의 **사진·캡처 읽기** 버튼을 씁니다.)

## 카톡·문자 자동 수집
주문 받는 안드로이드 폰에 MacroDroid를 설정하면, 들어오는 카톡·문자가 서버(Supabase)에 모이고
주문 목록 맨 위 **새로 들어온 주문**에 손님별로 정리돼 나타납니다. 확인 후 **확정**만 누르면 됩니다.
설정 방법은 [SETUP-PHONE.md](SETUP-PHONE.md)를 보세요.

- 매장 PC·휴대폰 어디서든 ⚙︎ 설정에 **매장 비밀번호**를 넣으면 같은 목록을 봅니다 (20초마다 새로고침).
- 서버: `supabase/functions/flower` (엣지 함수), `supabase/migration.sql` (테이블)
- 주문으로 확정하지 않은 메시지는 3일 뒤 서버에서 자동 삭제되고, **주문 아님**·**숨기기**를 누르면 바로 삭제됩니다.
- 비밀번호 없이 쓰면 예전처럼 이 기기의 브라우저에만 저장됩니다.

## 저장
서버에 연결하지 않으면 주문은 이 기기의 브라우저(localStorage)에만 저장됩니다. 설정(⚙︎)에서 백업 파일 저장·불러오기와 엑셀(CSV) 내보내기를 할 수 있습니다.

## 주문자·지역·상세보기
- 주문 목록에 **주문자 이름과 지역명**을 표시합니다. 지역명은 주소 앞부분에서 추출하며 입력·수정할 수 있습니다. 주문자의 거주지를 추측하지 않습니다.
- 검색창에서 주문자와 지역으로 찾을 수 있습니다. 기존 주문도 주소가 있으면 지역을 표시합니다.
- 주문 카드 또는 **상세보기**를 누르면 주문자·받는 분·상품·배송 정보·카드·원본 대화를 확인할 수 있습니다. 키보드로 카드를 선택하고 Enter/Space를 눌러도 열립니다.
- 상세보기에서 수정과 확인 문구 복사가 가능합니다. CSV와 백업에도 지역명을 보존합니다.

## 주문 알림
- 상단 **확인할 주문**에 미확정 새 주문 메시지, 접수 주문, 수령 임박, 시간이 지난 미완료 주문, 날짜·시간 미정 주문을 표시합니다. 검색/날짜 필터와 무관합니다.
- **확인**은 알림만 확인 처리합니다. 주문 완료와 다릅니다. **10분 뒤 알림**은 이 기기에 저장되며 새로고침해도 유지됩니다. 확인·미룬 알림에서 다시 표시할 수 있습니다.
- 수령 임박 기본값은 **1시간 전**이며 설정에서 30분/1시간/2시간으로 바꿀 수 있습니다. 접수 알림을 확인해도 수령 임박·지연 단계에는 새 알림이 표시됩니다.
- **기기 알림 켜기**를 누르고 브라우저에서 허용하면 앱 실행 중 기기 알림을 보냅니다. 개인정보가 잠금화면에 나타나지 않도록 알림 본문에는 이름·주소를 넣지 않습니다. 알림을 누르면 주문 상세 또는 새 주문함으로 연결됩니다.
- 앱을 완전히 닫으면 새로운 기기 알림은 발송되지 않습니다. 백그라운드에서는 브라우저가 확인 주기를 늦출 수도 있습니다. 서버 푸시는 별도 구축이 필요합니다.
- 앱을 닫은 뒤의 수령 알림은 상세보기의 **캘린더에 추가**에서 내려받은 `.ics` 파일을 캘린더 앱에 저장해 사용할 수 있습니다. 캘린더의 알림 권한/지원 여부를 확인하세요. 주문 수정·취소는 캘린더에 자동 반영되지 않습니다.
- 알림 확인/미루기와 기기 알림 설정은 기기별로 관리됩니다.

## 개발
- `parser.js` — 대화/문자에서 주문 정보를 뽑는 규칙 (브라우저·Node 공용)
- `app.js` — 화면 동작
- 테스트: `node --test flower-orders/*.test.js`
- 실행: `cd flower-orders && python3 -m http.server 8000` 후 http://localhost:8000
